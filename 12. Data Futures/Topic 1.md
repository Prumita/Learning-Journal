# Reference internal report from own organisation?
Could generally be confidential, do you want to be releasing or sharing? Happy to reference, then reference it the same. Surname year, bibliography at the end more detail.

Might wish to reference a quote instead, or putting someone else's quote into your own words. Bit more challenging to reference. Sometimes it's appropriate to reference and other times it has changed so much there's no longer a need to reference it. If in doubt, reference!

If it's a website article where it's all on one page you'd just write page 1, and then in bibliography you'd go into more detail on where it is.

Harvard referencing is Author, Year, Title.
